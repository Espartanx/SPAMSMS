# SPAMSMS 📱💥

**SPAMSMS** es una herramienta para Termux que permite enviar múltiples mensajes SMS automáticamente desde tu dispositivo Android.

> ⚠️ Úsalo con responsabilidad. Esta herramienta es solo para fines educativos y de prueba.

---

## ✅ Requisitos

Antes de usar SPAMSMS, asegúrate de tener instalado lo siguiente en Termux:

- [`termux-api`](https://wiki.termux.com/wiki/Termux:API)
- Permisos de SMS otorgados a Termux

---

## 📦 Instalación

Ejecuta el siguiente comando para instalar `termux-api`:

```bash
pkg install termux-api
